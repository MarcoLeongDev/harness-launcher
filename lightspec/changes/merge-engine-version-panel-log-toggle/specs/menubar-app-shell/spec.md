# Delta for Menubar App Shell

## MODIFIED Requirements
### Requirement: Tray Menu SF Symbols
The tray menu SHALL use explicit SF Symbol glyphs: a gear (gearshape) symbol
on the item that previously showed a switch-style glyph, and `arrow.up.right.square`
on the "Open in Browser" item.

#### Scenario: menu glyphs
- WHEN the user opens the tray menu
- THEN the target item shows the gear symbol and "Open in Browser" shows the square arrow-out glyph
